🔒 Contexto del Problema

En el mundo de la seguridad informática, la elección de un código de acceso es crítica. Los números primos son la base de los sistemas de cifrado más utilizados en el mundo, como RSA, porque son extremadamente difíciles de factorizar.

Un código numérico primo es más seguro porque no puede descomponerse en factores menores (excepto 1 y él mismo), lo que dificulta los ataques de fuerza bruta y los intentos de adivinación sistemática.

Ejemplos de códigos y su seguridad

🧮 Explicación del Algoritmo

Un número primo es aquel que solo puede dividirse exactamente entre 1 y sí mismo. Para verificarlo, contamos cuántos divisores tiene:

Ingresa el código → Contar divisores → ¿Exactamente 2? → ¡Es primo!

El algoritmo recorre todos los números desde 1 hasta el propio código usando un ciclo for. Por cada número que divide exactamente al código (sin residuo), incrementa un contador. Al final, si el contador es exactamente 2, el código es primo y se considera seguro.

Este método usa una sola variable contadora y el operador módulo % para verificar divisibilidad, sin necesidad de arrays ni funciones matemáticas complejas.

💻 ¿Cómo funciona el código JavaScript?

El siguiente código es la función principal del validador. Cada línea está comentada para explicar exactamente qué hace: 

// Función auxiliar: devuelve un ícono según el tamaño del código
function obtenerIcono(numero) {
    if (numero <= 10)   return "🔑";
    if (numero <= 100)  return "🔓";
    if (numero <= 1000) return "🛡️";
    if (numero <= 9999) return "🔒";
    return "🏰";
}

// Función principal que se ejecuta al presionar el botón
function validarCodigo() {

    // 1. Capturamos el valor del input usando getElementById
    var numero = parseInt(document.getElementById('codigo').value);
    var divResultado = document.getElementById('resultado');

    // 2. Validamos que el valor sea un número en rango válido
    if (isNaN(numero) || numero < 2 || numero > 999999) {
        divResultado.innerHTML =
            "<span class='error-msg'>⚠ Ingresa un número entre 2 y 999 999.</span>";
        return;
    }

    // 3. Iniciamos el contador de divisores en cero
    var contador = 0;

    // 4. Ciclo for: revisamos todos los números del 1 al propio código
    for (var i = 1; i <= numero; i++) {

        // Si el residuo de la división es 0, encontramos un divisor
        if (numero % i == 0) {
            contador = contador + 1;
        }
    }

    // 5. Si tiene exactamente 2 divisores, es primo
    var esPrimo = (contador == 2);

    // 6. Renderizamos el resultado con estilo en la página
    if (esPrimo) {
        divResultado.innerHTML =
            "<div class='res-valido'>" +
            "  <div class='res-icono'>" + obtenerIcono(numero) + "</div>" +
            "  <div class='res-titulo'>✔ Código Válido</div>" +
            "  <div class='res-numero'>" + numero + "</div>" +
            "  <div class='res-detalle'>Es un número primo — Código SEGURO</div>" +
            "  <div class='res-extra'>Divisores: solo 1 y " + numero + "</div>" +
            "</div>";
    } else {
        divResultado.innerHTML =
            "<div class='res-invalido'>" +
            "  <div class='res-icono'>⚠</div>" +
            "  <div class='res-titulo'>✘ Código No Válido</div>" +
            "  <div class='res-numero'>" + numero + "</div>" +
            "  <div class='res-detalle'>No es primo — Código NO SEGURO</div>" +
            "  <div class='res-extra'>Tiene " + contador + " divisores</div>" +
            "</div>";
    }
}
1

Captura: Lee el código ingresado con getElementById.

2

Validación: Verifica que el número esté entre 2 y 999 999.

3

Contador: Inicia en 0 para contar divisores.

4

Ciclo for: Recorre todos los números con numero % i == 0.

5

Decisión: Si el contador es exactamente 2, el código es primo.

6

Resultado: Muestra en pantalla si el código es seguro o no.

🏁 Conclusión

Los números primos no son solo un concepto matemático abstracto: son el fundamento de la seguridad digital moderna. Algoritmos como RSA protegen millones de transacciones bancarias y comunicaciones diarias gracias a la dificultad de factorizar números primos grandes.

Al programar este validador, comprobamos que con un ciclo, un contador y el operador módulo podemos construir una herramienta útil que aplica matemática real a un problema de seguridad informática, convirtiendo un concepto abstracto en algo funcional y concreto.
